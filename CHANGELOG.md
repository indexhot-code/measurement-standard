# Changelog

All notable changes to the IndexHot GEO Measurement Standard will be documented in this file.

## [1.0.0] - 2026-10-12
### Added
- Initial public release of the IndexHot GEO Measurement Standard.
- Defined the 3-layer measurement framework (Question Library, Citation Metrics, Cross-Platform Scoring).
- Established the distinction between Mention, Citation, and Absorption.
- Linked the standard to the open-source `geo-data` repository.
