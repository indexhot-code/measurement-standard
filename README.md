# The IndexHot GEO Measurement Standard v1.0

A public, reproducible framework for measuring how brands appear in AI search (ChatGPT, Perplexity, Gemini).

## Why a Standard Matters

Most Generative Engine Optimization (GEO) tools provide black-box scores. Users cannot see how the score is calculated, reproduce the results, or optimize against it. The IndexHot Measurement Standard aims to replace this opacity with a transparent, auditable, and governed methodology.

## The Framework

The standard defines a three-layer measurement model:

1. **Governed Question Library:** A defined mix of brand-specific and non-brand prompts to simulate real user discovery.
2. **Citation Metrics:** Rigorous definitions for Mention, Citation, and Absorption.
3. **Cross-Platform Scoring:** A weighted algorithm to normalize brand visibility across different AI models.
